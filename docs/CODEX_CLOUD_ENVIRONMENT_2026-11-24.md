## Сохранение для новых облачных чатов

В черновик конфигурации Codex сохранены полный `install_script` и `start_skill`; оба checkout с точными SHA также сохранены и подтверждены повторным чтением черновика. Успешный ответ инструмента: `status: saved`, `requires_publish: true`. `start_skill` начинает с CURRENT_HANDOFF.md, восстанавливает активацию и запрещает автоматический запуск испытаний, dispatch и изменение launch markers. Скрипт установки не меняет исходники, тесты и workflow.

Сохранение черновика не публикует среду. После подтверждения сохранения агентом владелец должен проверить и сохранить изменения в настройках среды, затем **Publish**. Публикация сохраняет файловый snapshot; процессы и авторизация времени выполнения не гарантированно переносятся. Восстановление в новом облачном чате в этой сессии не проверено: новый чат должен проверить SHA checkout, активацию, версии и доступ к требуемым артефактам. Не считать сам факт сохранения черновика доказательством публикации или восстановления.

## Ограничения

1. `/dev/kvm` отсутствует. Локальные аппаратно ускоренные эмуляторные испытания не подготовлены; образы эмулятора и AVD не создавались. Существующий CI API35 сохраняется без изменений. Реальные Samsung/Motorola, слышимый звук и длительные повторы этой машиной не проверены.
2. GitHub API (`api.github.com`) в текущем экземпляре получает proxy CONNECT 403; успешный Git-доступ не доказывает Actions/artifact API access. Получение архивов и проверка их содержимого в этой настройке не выполнялись. Сохранено добавление `api.github.com`, `dl.google.com`, `maven.google.com` к ограниченной сети при сохранении существующего preset package_managers. Настройки черновика ещё нужно применить/опубликовать. После применения повторить read-only API-запрос; если отказ останется, диагностировать разрешение Actions read, не запрашивать токен только из-за отсутствия CLI login.
3. Артефакты прежних запусков имеют 30-дневное хранение. Этот этап не сохраняет их вне GitHub и не продлевает срок; ссылки и точные ID остаются в CURRENT_HANDOFF.md. Приватные архивы и диагностические данные в Git не публиковались.
4. Gradle выводит необязательное предупреждение о недоступном каталоге метрик `/home/agent/.android`; оно не мешает успешным help/dependencies. Данные приложения и тестов не затронуты.
5. APK, тестовые suite и первичные доказательства здесь повторно не проверялись. Исторические результаты Alpha №3 и четыре неквалифицированных падения остаются в прежнем статусе. Следующее исследование требует отдельного задания владельца.
